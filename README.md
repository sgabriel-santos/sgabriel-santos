## 🚀 Projetos em destaque

### MechanicShop: sistema de oficina mecânica em microsserviços

Sistema dividido em serviços independentes que se comunicam por mensageria, com deploy em Kubernetes, observabilidade e pipeline de CI.

- [**mechanicshop-os-service**](https://github.com/sgabriel-santos/mechanicshop-os-service): gestão das ordens de serviço
- [**mechanicshop-budget-and-billing-service**](https://github.com/sgabriel-santos/mechanicshop-budget-and-billing-service): geração e pagamento de orçamentos
- [**mechanicshop-execution-service**](https://github.com/sgabriel-santos/mechanicshop-execution-service): execução dos orçamentos aprovados

**Stack:** FastAPI · RabbitMQ · PostgreSQL · MongoDB · Docker · Kubernetes · New Relic · GitHub Actions · pytest

### LLM Image Classifier: TCC em Engenharia de Computação

[![PyPI](https://img.shields.io/pypi/v/llm-image-classifier?style=flat-square&logo=pypi&logoColor=white&label=PyPI)](https://pypi.org/project/llm-image-classifier/)

Ferramenta no-code para treinar e avaliar modelos de classificação de imagens (InceptionV3, Xception e outros), com relatórios de métricas e um assistente virtual baseado em LLM que tira dúvidas sobre o treinamento e o desempenho do modelo. O projeto virou uma biblioteca publicada no PyPI e pode ser instalada com `pip install llm-image-classifier`.

- [**automatic-training-of-AI-models**](https://github.com/sgabriel-santos/automatic-training-of-AI-models): código-fonte
- [**llm-image-classifier**](https://pypi.org/project/llm-image-classifier/): pacote no PyPI

**Stack:** Python · FastAPI · TensorFlow/Keras · LLM (Groq)

### Vocabulary Builder: PWA pessoal para aprender inglês (em desenvolvimento)

PWA que transforma palavras e expressões em inglês anotadas no dia a dia em vocabulário ativo, com enriquecimento por IA, repetição espaçada (FSRS), pronúncia e diário. As decisões de arquitetura ficam registradas em ADRs, e o pipeline de CI roda lint, checagem de tipos, testes, validação de contrato da API e busca de segredos.

- [**vocabulary-builder**](https://github.com/sgabriel-santos/vocabulary-builder)

**Stack:** FastAPI · PostgreSQL · React · Vite · Docker · GitHub Actions
